# Getting help

- **How do I…?** Start with the [documentation](https://mobiumdev.github.io/):
  the quick start, the guides and a reference for every tool. Mobium's
  [SETUP.md](https://github.com/mobiumdev/mobium/blob/main/docs/SETUP.md)
  covers emulators, phones and simulators, and the setup errors that name the
  wrong cause.
- **Something fails for a reason that makes no sense:** run `mobium doctor`.
  It needs no device and no daemon, and names the fix for what it finds.
- **A bug, or something Mobium should do:** open an issue with the form in
  [mobium](https://github.com/mobiumdev/mobium/issues/new/choose), with the
  command and its output.
- **A vulnerability:** privately, as [SECURITY.md](SECURITY.md) says.

Mobium is maintained by one person. Issues are read, and answered as time
allows; there is no paid support.
