# mobiumdev/.github

Defaults for every repository under [github.com/mobiumdev](https://github.com/mobiumdev).
GitHub uses a file here for any repository that has none of its own.

| File | What it is | Repositories that have their own |
| --- | --- | --- |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 3.0, and how to report a problem | none |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute to each repository | mobium |
| [SECURITY.md](SECURITY.md) | Reporting a vulnerability privately | mobium |
| [SUPPORT.md](SUPPORT.md) | Where to ask for help | none |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Issue forms: a bug report and a request | mobium |
| [.github/pull_request_template.md](.github/pull_request_template.md) | What a pull request description covers | none |
| [profile/README.md](profile/README.md) | The organization's page on GitHub | — |
